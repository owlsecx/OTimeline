## 📌 Overview

OTimeline is an offline-first OwlSec tool for Filesystem Super-Timeline. It provides an interactive cyan terminal UI and a full CLI with multi-format export (TXT, Markdown, JSON, CSV, SARIF), designed for authorized security work on Linux.

---

## ✨ Features

- Build filesystem super-timelines from local evidence sources
- Bodyfile-oriented workflows and source listing helpers
- ATT&CK-aware tagging where timeline events map cleanly
- Offline DFIR-friendly processing
- Interactive exploration plus CLI batch mode
- Export timelines to standard report formats

---

## ⚙️ Requirements

- **Linux**
- **Go 1.21+** (stdlib only; `CGO_ENABLED=0`)

---

## 🚀 Usage

```bash
go build -ldflags="-s -w" -o OTimeline OTimeline.go
./OTimeline --help
./OTimeline --path /evidence --bodyfile
./OTimeline --input bodyfile.txt --format json
./OTimeline --list-sources
```
